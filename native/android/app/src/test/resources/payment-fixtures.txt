# Payment message fixtures, shared by the native parser tests (PaymentParserTest.java) and the
# JavaScript twin (tests/inbox/parse.test.mjs). When a bank or app changes its wording, add the new
# message here first, then teach both parsers.
#
# == <name>            starts a case
# kind: sms|app|share|mail  which parser runs
# from: <sender>        SMS sender id (sms), gpay|phonepe|paytm (app), or the sender's name as the mail app
#                       shows it (mail)
# title: <text>         notification title (app), or the email's subject (mail)
# text: <text>          message body, or the start of the email (mail); \n stands for a line break
# expect: none          the message must be skipped
# amount, dir, account, party, vpa, ref, channel, balance, bank
#                       expected fields; "-" means the field must be empty. Fields left out aren't checked.
